# Reining CJ Horses

Jeu de reining en 3D avec les chevaux du club CJ Horses, créé par Marine LYS (Le Club des Bernards) avec Claude.

Jouer : ouvrir `index.html`, ou la page GitHub Pages du dépôt.

Crédits : modèle 3D « HORSE - Realistic 3D Model (DEMO FREE) » et pack d'animations « Horse » de WildMesh 3D (modèle sous licence CC BY-NC 4.0, usage non commercial). Three.js (MIT).
